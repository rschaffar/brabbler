# Terminal font

`JetBrainsMonoNerdFontMono-Regular.ttf` is JetBrains Mono Nerd Font Mono, version
3.5.0 (JetBrains Mono 2.304), from the [Nerd Fonts project](https://github.com/ryanoasis/nerd-fonts).
It is served only to browsers using the terminal's Nerd Font option; no system
font installation is needed. JetBrains Mono is copyright 2020 The JetBrains
Mono Project Authors. The font is distributed under the SIL Open Font License
1.1; see [OFL.txt](OFL.txt). Nerd Fonts patches JetBrains Mono with icon glyphs
from its collection of icon fonts; see the [Nerd Fonts license and credits](https://github.com/ryanoasis/nerd-fonts#license).
