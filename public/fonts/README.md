# Bundled fonts and notices

## Terminal Nerd Font

`JetBrainsMonoNerdFontMono-Regular.ttf` is JetBrains Mono Nerd Font Mono from
[Nerd Fonts 3.5.0](https://github.com/ryanoasis/nerd-fonts/tree/v3.5.0), based on
JetBrains Mono 2.304. It needs no system-font installation. The base font is
copyright 2020 The JetBrains Mono Project Authors; its complete SIL OFL 1.1 notice
is [OFL.txt](OFL.txt). The patched binary SHA-256 is
`474634cb9b0697a3a10b3da589e896794e1128b0c7c9b49678ec2e03194ce45a`.

Nerd Fonts merges, remaps and scales third-party glyphs. Their own notices are
preserved in [licenses/](licenses/README.md); the base font's OFL is not a blanket
relicense of all glyph sources. Logos and project names remain subject to their
owners' trademark rights; their inclusion implies no endorsement.
