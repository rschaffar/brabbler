# Upgrade Pi Web to Pi SDK 1.0.0

## Goal

Pin the four published `@earendil-works/pi-{agent-core,ai,coding-agent,tui}` packages to 1.0.0 and verify existing Pi Web integrations with the matching Nix dependency cache.

## Plan Relationship

This follows the [0.99.1 upgrade](2026-09-29_pi-sdk-0.99.1-upgrade-plan.md). Existing Git-workflow plans own feature development; this task only revalidates SDK compatibility and source-discovery evidence.

## Non-Goals

No production build, publication, live credentials/model calls, new MCP/image/TUI features, or worktree cleanup. Local integration into `rst-main` requires separate exact-state approval.

## Risks and Recovery

0.99.2 changes MCP initialization and reload tool selection; 1.0.0 changes MCP OAuth and codemode behavior. Typechecking alone cannot verify runtime compatibility. Revalidate the SDK-pinned context discovery contract before changing its marker. Older captured source reviews must fail closed and require renewal, not implicit migration. Keep the feature isolated if verification is blocked; do not modify existing user state.
