## Risks

0.99.0 is the substantial change (0.99.1 is a small follow-up). The new SDK adds tool/runtime features and changes built-in extension and provider semantics. Pi Web uses some private SDK fields and a source collector marked `pi-0.87.1-context-v1`. Published types and unit tests alone cannot prove that interactive runs work. The collector marker must only change after verifying the SDK context-file ordering and shadow-selection behavior; old captured task-source snapshots must fail closed rather than silently changing meaning.

## Rollback / Recovery

The upgrade changes tracked dependency versions and matching source-contract metadata, not existing user settings or task-source records. Existing records of an older discovery version should be re-reviewed rather than migrated implicitly. If compatibility cannot be demonstrated, keep the feature branch separate from `rst-main`; no production build or publish is authorized.
