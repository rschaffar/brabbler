## Decisions and historical work

[ADRs](adr/) record durable decisions. The [plan index](plans/README.md) distinguishes
active proposals from archived implementation evidence. Historical commands and
results describe their recorded inputs; they are not current instructions or new
execution/publication authority. Private evidence must not be copied into plans.
